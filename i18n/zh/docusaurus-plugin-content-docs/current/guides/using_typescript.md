# TypeScript 支持 {#typescript-support}

从 v3.1 起，DHTMLX Diagram 库提供了使用 TypeScript 定义文件的功能。TypeScript 的内置支持应该可以开箱即用。

您可以直接在我们的<a href="https://snippet.dhtmlx.com/ybpmz0zk"  target="_blank">代码片段工具</a>中试用该功能。
:::

## 使用 TypeScript 的优势 {#advantages-of-using-typescript}

为什么我们建议您将 DHTMLX Diagram 与 TypeScript 结合使用？

TypeScript 的主要优势在于，它能让您准确了解 DHTMLX Diagram 库的 API 期望接收哪种类型的数据。

由于类型检查与自动补全功能相结合，可以帮助您避免潜在的错误，并且无需不断查阅文档即可编写代码，因此构建应用程序的方式变得更加智能。
