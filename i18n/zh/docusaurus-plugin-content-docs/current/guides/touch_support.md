# 触摸支持

![](/img/touch_support.png)

从 4.2 版本及更高版本开始，DHTMLX Diagram 库提供了开箱即用的内置触摸支持。

当您通过触摸屏幕与应用程序交互时，点按操作与鼠标点击具有相同的效果。
因此，点击事件（在点击、双击项目时触发）在触摸屏设备上将继续正常工作。请注意，mouseover 事件不会被触发。

触摸支持可识别以下触摸手势：

- **双击** - 用于编辑形状/组/泳道的文本；用于创建和编辑连接线的文本
- **按住并拖动** - 用于调用 `blockSelection` 并选择多个项目
- **拖动** - 用于拖动形状/组/泳道；用于从编辑器的左侧面板拖动形状/文本/组/泳道
