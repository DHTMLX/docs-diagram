# scale

### 描述 {#description}

@short: 可选。定义 Diagram Editor 的缩放比例

### 用法 {#usage}

~~~jsx
scale?: number;
~~~

### 默认配置 {#default-config}

~~~jsx
scale: 1
~~~

### 示例 {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    scale: 0.9
});
~~~
