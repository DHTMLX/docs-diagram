# editMode

### 描述 {#description}

@short: 可选。隐藏/显示 editor 的左右面板

### 用法 {#usage}

~~~jsx
editMode?: boolean;
~~~

### 示例 {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    editMode: false
});
~~~
