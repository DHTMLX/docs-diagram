# scale

### 描述 {#description}

@short: 可选。定义 Diagram 的缩放比例

### 用法 {#usage}

~~~jsx
scale?: number;
~~~

### 默认配置 {#default-config}

~~~jsx
scale: 1
~~~

### 示例 {#example}

~~~jsx
const diagram = new dhx.Diagram("diagram_container", {
    scale: 0.7
});
~~~
