# scale

### 설명 {#description}

@short: 선택 사항입니다. diagram editor의 배율을 정의합니다

### 사용법 {#usage}

~~~jsx
scale?: number;
~~~

### 기본 설정 {#default-config}

~~~jsx
scale: 1
~~~

### 예제 {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    scale: 0.9
});
~~~
