# Diagram 항목

다음 가이드에서는 사용 가능한 모든 Diagram 항목 유형을 소개하고 해당 구성의 세부 사항을 설명합니다.

import DocCardList from '@theme/DocCardList';
import {useCurrentSidebarCategory} from '@docusaurus/theme-common';

<DocCardList items={useCurrentSidebarCategory().items}/>

가이드를 읽은 후에는 개발 프로세스를 가속화할 수 있도록 다음 API 섹션을 확인해 보세요.

- [Items API 속성](/category/items-api/)
- [DataCollection API](/api/data_collection/) (도형, 선, 선 제목, 그룹, 스윔레인과 같은 데이터 항목의 추가, 제거, 필터링 등을 지원합니다)
- [CellManager API](/api/cell_manager/) (스윔레인 셀의 추가, 제거, 이동 등을 지원합니다)
- [Selection API](/api/selection/)
- [Diagram API](api/diagram/api_overview.md)
- [Diagram Editor API](api/diagram_editor/editor/api_overview.md)
