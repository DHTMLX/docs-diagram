# Элементы Diagram {#diagram-items}

Следующие руководства знакомят со всеми доступными типами элементов Diagram и рассматривают особенности их настройки.

import DocCardList from '@theme/DocCardList';
import {useCurrentSidebarCategory} from '@docusaurus/theme-common';

<DocCardList items={useCurrentSidebarCategory().items}/>

После изучения руководств вы можете просмотреть следующие разделы API, чтобы ускорить процесс разработки:

- [Свойства API элементов](/category/items-api/)
- [DataCollection API](/api/data_collection/) (позволяет добавлять, удалять, фильтровать элементы данных (такие как фигуры, линии, заголовки линий, группы, дорожки) и т. д.)
- [CellManager API](/api/cell_manager/) (позволяет добавлять, удалять, перемещать ячейки дорожки и т. д.)
- [Selection API](/api/selection/)
- [Diagram API](api/diagram/api_overview.md)
- [Diagram Editor API](api/diagram_editor/editor/api_overview.md)

Чтобы узнать, как загружать, настраивать и редактировать элементы, а также выполнять с ними различные операции, ознакомьтесь с руководствами:

- [Загрузка и сохранение данных](guides/loading_data.md)
- [Настройка элементов](guides/customization.md)
- [Встроенное редактирование](guides/inline_editing.md)
- [Управление элементами](guides/manipulating_items.md)
