# scale

### Описание {#description}

@short: Необязательный параметр. Определяет масштаб диаграммы

### Использование {#usage}

~~~jsx
scale?: number;
~~~

### Конфигурация по умолчанию {#default-config}

~~~jsx
scale: 1
~~~

### Пример {#example}

~~~jsx
const diagram = new dhx.Diagram("diagram_container", {
    scale: 0.7
});
~~~
