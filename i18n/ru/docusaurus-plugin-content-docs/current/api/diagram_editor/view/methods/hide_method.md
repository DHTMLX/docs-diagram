# hide()

### Описание {#description}

@short: Скрывает панель инструментов, панель редактирования и панель фигур Diagram Editor.

:::info
Если вам нужно скрыть элементы `Toolbar`, `Editbar` и `Shapebar` по отдельности, вызовите метод `hide()` с соответствующим параметром. Чтобы скрыть все эти элементы, вызовите метод `hide()` без параметров.
:::

### Использование {#usage}

~~~jsx
hide(view?: "toolbar" | "shapebar" | "editbar"): void;
~~~

### Параметры {#parameters}

- `toolbar` - (опционально) скрывает панель инструментов
- `shapebar` - (опционально) скрывает панель фигур
- `editbar` - (опционально) скрывает панель редактирования

### Пример {#example}

~~~jsx {5-6,8-9}
const editor = new dhx.DiagramEditor("editor_container", {
    type: "default"
});

// скрывает панель фигур
editor.view.hide("shapebar");

// скрывает панель фигур, панель редактирования и панель инструментов
editor.view.hide();
~~~
