# editMode

### Описание {#description}

@short: Необязательный. Скрывает/показывает левую/правую панели редактора

### Использование {#usage}

~~~jsx
editMode?: boolean;
~~~

### Пример {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    editMode: false
});
~~~
