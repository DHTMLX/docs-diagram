# type

### Описание {#description}

@short: Обязательный. Определяет режим работы редактора Editor

### Использование {#usage}

~~~jsx
type?: "default" | "org" | "mindmap";
~~~

### Подробности {#details}

Diagram Editor можно инициализировать в одном из трёх режимов:

- `type:"default"` используется для визуализации связей между сущностями

<iframe src="https://snippet.dhtmlx.com/xshe9ut7?mode=result" frameborder="0" class="snippet_iframe" width="100%" height="600"></iframe>

- `type:"org"` используется для отображения структуры группы людей путём представления их взаимосвязей в иерархическом порядке

<iframe src="https://snippet.dhtmlx.com/og4qm3ja?mode=result" frameborder="0" class="snippet_iframe" width="100%" height="600"></iframe>

- `type:"mindmap"` используется для организации информации по определённой теме путём представления основной идеи, окружённой связанными с ней идеями
