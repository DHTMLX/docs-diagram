# scale

### Описание {#description}

@short: Необязательный параметр. Определяет масштаб редактора диаграмм

### Использование {#usage}

~~~jsx
scale?: number;
~~~

### Конфигурация по умолчанию {#default-config}

~~~jsx
scale: 1
~~~

### Пример {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    scale: 0.9
});
~~~
