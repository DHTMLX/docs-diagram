# scale

### Beschreibung {#description}

@short: Optional. Legt die Skalierung des Diagramms fest

### Verwendung {#usage}

~~~jsx
scale?: number;
~~~

### Standardkonfiguration {#default-config}

~~~jsx
scale: 1
~~~

### Beispiel {#example}

~~~jsx
const diagram = new dhx.Diagram("diagram_container", {
    scale: 0.7
});
~~~
