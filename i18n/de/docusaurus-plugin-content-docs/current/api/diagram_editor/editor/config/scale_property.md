# scale

### Beschreibung {#description}

@short: Optional. Legt den Maßstab des Diagram Editors fest

### Verwendung {#usage}

~~~jsx
scale?: number;
~~~

### Standardkonfiguration {#default-config}

~~~jsx
scale: 1
~~~

### Beispiel {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    scale: 0.9
});
~~~
