# type

### Beschreibung {#description}

@short: Erforderlich. Legt den Modus des Diagram Editors fest

### Verwendung {#usage}

~~~jsx
type?: "default" | "org" | "mindmap";
~~~

### Details

Der Diagram Editor kann in einem von drei Modi initialisiert werden:

- `type:"default"` wird verwendet, um Beziehungen zwischen bestimmten Entitäten zu visualisieren

<iframe src="https://snippet.dhtmlx.com/xshe9ut7?mode=result" frameborder="0" class="snippet_iframe" width="100%" height="600"></iframe>

- `type:"org"` wird verwendet, um die Struktur einer Gruppe von Personen darzustellen, indem ihre Beziehungen in hierarchischer Reihenfolge präsentiert werden

<iframe src="https://snippet.dhtmlx.com/og4qm3ja?mode=result" frameborder="0" class="snippet_iframe" width="100%" height="600"></iframe>

- `type:"mindmap"` wird verwendet, um Informationen zu einem Thema zu strukturieren, indem das Hauptkonzept von zugehörigen Ideen umgeben dargestellt wird

<iframe src="https://snippet.dhtmlx.com/lo1vm0e8?mode=result" frameborder="0" class="snippet_iframe" width="100%" height="600"></iframe>
