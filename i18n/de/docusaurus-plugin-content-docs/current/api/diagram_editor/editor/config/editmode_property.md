# editMode

### Beschreibung {#description}

@short: Optional. Blendet die linken/rechten Panels des Editors ein oder aus

### Verwendung {#usage}

~~~jsx
editMode?: boolean;
~~~

### Beispiel {#example}

~~~jsx
const editor = new dhx.DiagramEditor("editor_container", {
    editMode: false
});
~~~
