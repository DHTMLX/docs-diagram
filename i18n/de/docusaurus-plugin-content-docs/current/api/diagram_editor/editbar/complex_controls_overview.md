# Komplexe Steuerelemente {#complex-controls}

Sie können die komplexen Steuerelemente der Editbar verwenden, um die Editbar für Diagram-Elemente zu konfigurieren. Nachfolgend finden Sie die Liste der komplexen Steuerelemente. Öffnen Sie den entsprechenden Abschnitt, um die detaillierte Beschreibung der Konfigurationseigenschaften für jedes Steuerelement anzuzeigen.

:::info
Weitere Informationen zur Konfiguration finden Sie in der Anleitung [Editbar-Konfiguration](guides/diagram_editor/editbar.md)!
:::
