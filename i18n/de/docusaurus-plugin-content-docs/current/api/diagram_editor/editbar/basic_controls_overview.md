# Grundlegende Steuerelemente {#basic-controls}

Sie können die grundlegenden Steuerelemente der Editbar eigenständig verwenden oder auf ihrer Basis komplexe Steuerelemente erstellen. Nachfolgend finden Sie die Liste der grundlegenden Steuerelemente. Öffnen Sie den entsprechenden Abschnitt, um die detaillierte Beschreibung der Konfigurationseigenschaften für jedes Steuerelement anzuzeigen.

:::info
Weitere Informationen zur Konfiguration finden Sie in der Anleitung [Editbar-Konfiguration](guides/diagram_editor/editbar.md)!
:::
